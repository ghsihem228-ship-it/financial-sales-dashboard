# 💰 Financial Sales Dashboard

An interactive financial dashboard built with Python and Streamlit to analyze sales and profit data.

---

## 📊 Overview

This project allows users to:
- Analyze sales by region
- Analyze profit by product
- Track sales trends over time
- Use interactive filters for better insights

---

## 🛠️ Tools Used

- Python
- Pandas
- Matplotlib
- Streamlit

---

## 📈 Features

- Interactive filters (Region / Product)
- KPI Metrics:
  - Total Sales
  - Total Profit
  - Profit Margin
- Visualizations:
  - Sales by Region
  - Profit by Product
  - Sales Trend Over Time
